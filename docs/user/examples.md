# Example Queries

Seven understands natural language. These examples show common phrasings — you don't need to match them exactly.

## Help and manual

```
help
what can you do for me
user manual
```

## Who owned a target?

```
Who did mantis?
Who rooted json last?
Who can help me with Forest challenge?
Who solved baby?
```

## Target info

```
Lame

what's fresh
```
